## 📋 เช็กลิสต์ทดสอบสำหรับผู้ทดสอบ (Tester Action Items)

### 1. การติดตั้งและการตรวจสอบไฟล์ (Installation Phase)
- [ ] **TC-01 [Checksum]:** ตรวจสอบค่า SHA-256 ของ `NekoTracker-Setup-v7.1.0.exe` ตรงกับ `f11264c7ff9d51b0541ba28ad78e25fb317a54e2adef0c5067a9ebe916d6c5e5`
- [ ] **TC-02 [Zero-UAC]:** ดับเบิลคลิกตัวติดตั้ง รันได้ทันทีโดย **ไม่มี** หน้าต่างเตือน UAC เด้งถามสิทธิ์ Admin
- [ ] **TC-03 [Per-User Path]:** ติดตั้งลงโฟลเดอร์ `%LOCALAPPDATA%\NEKO FAMILY\NekoTracker` ถูกต้อง
- [ ] **TC-04 [Shortcuts]:** พบบน Desktop 1 ไอคอน และ Start Menu พบโฟลเดอร์ NEKO Tracker และทางลัด Uninstall

### 2. การเปิดโปรแกรมและหน้าต่าง (First-Launch & Window Behavior)
- [ ] **TC-05 [No CMD Window]:** เปิดโปรแกรมขึ้นมาเป็นหน้าต่าง GUI โทนพาสเทลสวยงาม ไม่มีหน้าต่าง Command Prompt ดำ
- [ ] **TC-06 [Minimize Fix]:** คลิกปุ่มย่อหน้าต่าง (`_`) ย่อลง Taskbar ได้อย่างสมบูรณ์ และ **ไม่เด้งกลับขึ้นมาเอง**
- [ ] **TC-07 [Typography]:** ตัวหนังสือภาษาไทย/อังกฤษ คมชัด สละสลวย ไม่ล้นกรอบ
- [ ] **TC-08 [Baseline State]:** ยอด Meseta เริ่มต้นที่ 0 ℳ, M/hr 0.00, สถานะขึ้น "กรุณาเลือกโฟลเดอร์ Log..."

### 3. ระบบคู่มือและชุมชน (Guide & Community)
- [ ] **TC-09 [Guide Tabs]:** เปิด "คู่มือการใช้งาน" สลับดูเนื้อหาครบทั้ง 5 แท็บ
- [ ] **TC-10 [Discord Link]:** คลิก "คัดลอกลิงก์ Discord" ได้ URL `https://discord.gg/fkjXW9AJ6a` และปุ่มเปิด Discord ทำงานได้

### 4. การอ่าน Log และ Zero-Login (Log Ingestion & Telemetry)
- [ ] **TC-11 [Zero-Login]:** ตรวจพบชื่อตัวละครจริงหรือชื่อจากไฟล์ Log อัตโนมัติ (ไม่ถามรหัสผ่านใดๆ)
- [ ] **TC-12 [Live Tracking]:** ตัวเลข Meseta วิ่งขึ้นสดเมื่อเก็บเงินในเกม, M/hr เริ่มนับ, รายการไอเทมดรอปขึ้นตาราง
- [ ] **TC-13 [Test Mode Bypass]:** หากทดสอบบนเครื่องที่ไม่มีเกม ให้เลือกโฟลเดอร์ที่ชื่อ `sample_logs` -> ป้ายเหลือง `[TEST MODE]` ปรากฏ และอ่านข้อมูลได้ทันที

### 5. ฟังก์ชันเสริมและสงครามพิกัด (Features & ARKS War Room)
- [ ] **TC-14 [Watchlist]:** บันทึกชื่อไอเทมใน Watch List แล้วเปิดสวิตช์กรอง -> แสดงเฉพาะไอเทมที่เลือก
- [ ] **TC-15 [Overlay Mode]:** เปิด Gadget Mini/Full Overlay ลอยทับหน้าจออื่นได้ และลากย้ายตำแหน่งได้อิสระ
- [ ] **TC-16 [War Room V9]:** สลับเข้าโหมดสงคราม เลือก Landmark (Core [0, 0] ฯลฯ) หรือพิมพ์พิกัด `15, -6, 2` สำเร็จ
- [ ] **TC-17 [Cloud Sync]:** กดปุ่มซิงค์ข้อมูล ขึ้นสถานะซิงค์สำเร็จด้วย Version `7.1.0`
- [ ] **TC-18 [Multi-Language]:** สลับภาษาอังกฤษ (EN), ไทย (TH), ญี่ปุ่น (JA) ได้สดทันที ไม่ต้องรีสตาร์ท
- [ ] **TC-19 [Reset]:** กดยืนยันรีเซ็ตข้อมูลรอบฟาร์ม -> เงินเซสชันกลับเป็น 0 แต่กระเป๋าและตัวตนไม่หาย

### 6. การถอนการติดตั้งอย่างสะอาดหมดจด (Clean Teardown)
- [ ] **TC-20 [In-App Uninstall]:** เปิดคู่มือ กดปุ่ม `🗑️ ถอนการติดตั้ง (Uninstall)` -> โปรแกรมหลักปิดตัวทันทีเพื่อคลายไฟล์ล็อค และหน้าต่างถอนการติดตั้งเปิดขึ้นมา
- [ ] **TC-21 [Clean Purge]:** ถอนการติดตั้งเสร็จ ไฟล์ใน `%LOCALAPPDATA%\NEKO FAMILY\NekoTracker` และทางลัดถูกลบออกอย่างหมดจด
