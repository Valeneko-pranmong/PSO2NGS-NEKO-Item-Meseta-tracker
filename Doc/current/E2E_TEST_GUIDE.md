## 🎯 วัตถุประสงค์และขอบเขตการทดสอบ (Scope & Objectives)

เอกสารฉบับนี้กำหนดขั้นตอนการทดสอบแบบ **End-to-End (E2E)** สำหรับผู้ทดสอบที่เป็นมนุษย์ (Human / Manual QA Testing) ครอบคลุมวงจรชีวิตการใช้งานซอฟต์แวร์จริงแบบ 100% ตั้งแต่:
1. การตรวจสอบความสมบูรณ์ของไฟล์ติดตั้งก่อนรัน
2. การติดตั้งแบบ Per-User โดยไม่ใช้สิทธิ์ Administrator (Zero-UAC Elevation)
3. การตรวจสอบทางลัดและการจัดวางโฟลเดอร์ตามมาตรฐาน
4. การเปิดโปรแกรมครั้งแรกและการควบคุมหน้าต่าง (Window Minimize Fix)
5. การใช้งานคู่มือในแอปและการเชื่อมต่อชุมชน Discord
6. การตรวจจับตัวตนแบบ Zero-Login และการอ่านข้อมูล Meseta/Item สด
7. การทดสอบทั้งกรณีเล่นเกมจริง และกรณีเครื่องทดสอบที่ไม่มีเกม (Test Mode)
8. การกรองไอเทมเป้าหมาย (Watchlist Filter)
9. โหมด Gadget Overlay (Mini & Full Mode)
10. ห้องปฏิบัติการสงครามพิกัด ARKS Coordinate War Room V9 และการซิงค์ Cloud
11. การสลับภาษาแบบทันที (Dynamic In-Flight Language Switching: EN / TH / JA)
12. การรีเซ็ตข้อมูลและระบบ Anti-Tamper Guard
13. การถอนการติดตั้งอย่างสมบูรณ์ตามมาตรฐาน 4 ช่องทาง (4-Tier Clean Teardown)

### Phase 12: การถอนการติดตั้งอย่างสมบูรณ์แบบ 4 ช่องทาง (4-Tier Uninstallation & Clean Teardown)

> **วัตถุประสงค์:** พิสูจน์ว่าผู้ใช้งานสามารถถอนการติดตั้งโปรแกรมได้อย่างราบรื่นและหมดจด ไม่ว่าผ่านช่องทางใดก็ตามใน 4 ช่องทางมาตรฐาน

* [ ] **12.1 ทดสอบช่องทางที่ 1: การค้นหาผ่าน Windows Start Menu:**
  - กดปุ่ม Windows พิมพ์ค้นหา `Uninstall NEKO` หรือ `ถอนการติดตั้ง`
  - ตรวจพบไอคอนตัวถอนการติดตั้ง
* [ ] **12.2 ทดสอบช่องทางที่ 2: สคริปต์ฉุกเฉินในโฟลเดอร์โปรแกรม (`Uninstall.bat`):**
  - เปิดไปที่ `%LOCALAPPDATA%\NEKO FAMILY\NekoTracker`
  - พบคลิกไฟล์ `Uninstall.bat` ซึ่งจะทำการเรียก `unins000.exe` ได้ทันทีแม้ทางลัด Start Menu จะหายไป
* [ ] **12.3 ทดสอบช่องทางที่ 3: เมนู Settings ของ Windows:**
  - เปิด `Settings > Apps > Installed apps` บน Windows 10/11
  - ค้นหา `NEKO Item & Meseta Tracker (v7.1.0)`
  - ปรากฏปุ่ม Uninstall ให้คลิกได้ตามมาตรฐาน Windows
* [ ] **12.4 ทดสอบช่องทางที่ 4 (สำคัญที่สุด): ปุ่มถอนการติดตั้งในแอป (In-App Uninstall Trigger):**
  - ในโปรแกรม NekoTracker คลิกเปิดปุ่ม **"คู่มือการใช้งาน (Guide)"**
  - ที่มุมล่างขวาของหน้าต่างคู่มือ คลิกปุ่ม **`🗑️ ถอนการติดตั้ง (Uninstall)`**
  - ปรากฏกล่องยืนยัน: "คุณแน่ใจหรือไม่ว่าต้องการถอนการติดตั้ง NEKO Item & Meseta Tracker?"
  - กดยืนยัน (Yes)
  - **เกณฑ์การผ่าน (PASS):**
    1. **หน้าต่างโปรแกรม NekoTracker ต้องปิดตัวลงทันที** เพื่อคลายไฟล์ล็อค (Release File Locks)
    2. หน้าต่างตัวถอนการติดตั้ง `unins000.exe` เด้งขึ้นมาถามความยินยอม
    3. กดยืนยันการถอนการติดตั้ง
    4. หลอดการถอนการติดตั้งทำงานจนเสร็จสมบูรณ์โดยไม่มี Error แจ้งว่าไฟล์กำลังถูกใช้งาน (File in use)
* [ ] **12.5 การตรวจสอบความสะอาดหมดจดหลังถอนการติดตั้ง (Clean Purge Audit):**
  - ตรวจสอบโฟลเดอร์: `%LOCALAPPDATA%\NEKO FAMILY\NekoTracker`
    - ไบนารี `NekoTracker.exe`, โฟลเดอร์ `_internal\`, และไฟล์การตั้งค่าถูกลบออกทั้งหมด
  - ตรวจสอบหน้า Desktop: ไอคอนทางลัด `NEKO Item & Meseta Tracker` หายไป
  - ตรวจสอบ Start Menu: โฟลเดอร์ `NEKO Item & Meseta Tracker` หายไป
  - ตรวจสอบ Task Manager: ไม่มี Process `NekoTracker.exe` ค้างหลงเหลืออยู่
